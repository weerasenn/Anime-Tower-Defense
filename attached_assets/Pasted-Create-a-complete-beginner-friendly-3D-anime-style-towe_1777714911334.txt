Create a complete beginner-friendly 3D anime-style tower defense game using JavaScript and Three.js that runs in a browser (Replit compatible).

This game must include a full lobby system, unit inventory, summoning (gacha), evolutions, boss fights, multiple modes, anime-style abilities, and ORIGINAL anime-inspired characters (not based on or copied from any existing anime).

---

## ANIME-STYLE UNIT DESIGN RULE

All characters must feel like they belong in a high-energy anime world:

* Dramatic names
* Elemental or supernatural powers
* Strong visual identity (glowing effects, aura colors, energy types)
* Clear role types (tank, assassin, mage, support, sniper)

## EVOLUTION SYSTEM

Each character evolves twice:

Example:
Kai Blade →

* Kai Ascended Blade →

  * Kai Infinity Blade

Akira Emberstorm →

* Akira Infernal Form →

  * Akira Phoenix Emperor

Drakon Pyroclast →

* Drakon Awakened →

  * Drakon Eternal Sovereign

Evolution Features:

* Increased stats
* New aura effects (stronger glow, particles, trails)
* Ability upgrades or new abilities
* Size/visual transformation

---

## GACHA SYSTEM (SUMMONING)

Currencies:

* Coins (standard summons)
* Gems (rare summons)

Drop Rates:

* Common: 60%
* Rare: 25%
* Epic: 10%
* Legendary: 5%

Summon System:

* Animated summon reveal screen
* Rarity-based lighting effects
* Character “materialization” animation

Duplicates:

* Converted into upgrade shards/materials
